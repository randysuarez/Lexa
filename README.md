## 🌟 What Is Lexa?

Most writing tools want you to paste your text into their website or install a heavy browser extension that watches everything you type. Lexa works differently. It is a small menu bar app that waits for you to ask for help.

When you select text and trigger Lexa, it sends only that selection to the writing engine you chose, gets an improved version back, and puts it where you need it. That is the whole idea. Small, fast, and out of the way.

Because it works on selected text rather than an entire document, Lexa fits into whatever you are already doing — writing an email, drafting a message, filling in a form, or posting on a forum.

## 🖱️ How to Use Lexa

The first run is where you connect Lexa to a writing engine. After that, daily use takes seconds.

1. **Open the menu.** Click the Lexa icon in your menu bar.
2. **Choose a writing engine.** Pick the option you want to use — a free online service, a model running on your own Mac, or your existing ChatGPT or Claude account.

5. **Use it anywhere.** From then on, select text in any application and ask Lexa to correct it, clarify it, change its tone, or translate it.

That is the entire workflow. There is nothing to configure every day, and no dashboard to check.

## 🔌 Choosing Your Writing Engine

Lexa does not lock you into one provider, which is one of its best qualities. You have three broad paths:

**Free online service.** The easiest starting point. No account, no cost, and nothing to install beyond Lexa itself. Good for occasional use and light edits.

**A local model.** This runs the writing engine on your own Mac. Nothing leaves your computer, which is the strongest privacy option, and there are no usage limits. The trade-off is that you need to install a helper program first and have enough memory for the model to run comfortably.

**Your own ChatGPT or Claude subscription.** If you already pay for one of these, Lexa can use it, which means you get high-quality rewrites without paying for anything extra. Lexa connects to your account and uses the access you already have.

You can switch between these options at any time from the menu. Many people start with the free option, try a local model out of curiosity, and settle on whichever feels best for their daily work.

## 🛠️ Common Questions

**Lexa is in my menu bar but nothing happens when I select text.**
Make sure you are triggering Lexa with the shortcut shown in its menu, and that the text is actually selected before you trigger it. Some apps need you to click into the text field first.

**My writing engine is not responding.**
Check your internet connection if you are using an online service. If you are using a local model, confirm that the helper program is running in the background. Switching engines temporarily is a quick way to find out whether the problem is Lexa or the engine.

**Can I undo a rewrite?**
Yes. Lexa replaces selected text, so the usual undo shortcut in the app you are working in will bring back your original wording.

**Does Lexa read everything I type?**
No. It only works on text you actively select and send to it. It is not a keyboard logger and it does not run in the background watching your typing.
